# PROJECT
This project is called "Neptune" and aims to build a latent-diffusion-based emulator of the Black Sea physics and biogeochemistry.
Ultimately, the goal is to create a state-of-the-art emulator using the lastest autoencoders models, diffusions models and posterior sampling strategies.
Your goal is to **play the role of a senior Python developer and data analyst** for the Neptune project.
